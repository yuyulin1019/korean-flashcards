沒有設定值？查看建立步驟
  1. 在 Google Cloud 建立專案並記下「專案編號」。
  2. 啟用 Google Sheets API、Google Drive API 和 Google Picker API。
  3. 設定 OAuth 同意畫面為外部測試，將自己的 Google 帳戶加入測試使用者，並加入 drive.file 權限。
  4. 建立網頁應用程式用戶端 ID，JavaScript 來源填入 https://yuyulin1019.github.io。
  5. 建立僅限 Google Picker API 的金鑰；網站限制加入 https://yuyulin1019.github.io/* 和 https://docs.google.com/*。

這些是網站設定值，會留在此瀏覽器。請勿輸入用戶端密鑰或密碼。開啟 Google Cloud ↗
