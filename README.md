# 韓文手寫字卡

以「看到中文、手寫韓文、翻開答案自我核對」為核心的單字複習網站。翻開字卡後可連到 Naver 韓語詞典搜尋該詞，再播放詞典提供的發音。

## 使用方式

直接開啟 `index.html`。可在「匯入筆記照片」選擇手寫單字筆記照片，按「辨識照片」後校對文字，再整理成每行「韓文, 中文」並加入字卡。也可直接在「編輯單字」中維護清單。

照片 OCR 由瀏覽器中的 Tesseract.js 執行；首次使用時需要網路下載程式與韓文、繁體中文辨識資料。一般 OCR 對手寫內容可能辨識不準，匯入前請校對。Naver 發音按鈕會開啟詞典搜尋結果，使用者在 Naver 頁面點發音圖示播放；目前沒有直接嵌入 Naver 詞典音檔。單字目前存在瀏覽器的 `localStorage`，只在同一個瀏覽器設定檔可見。

## 後續資料儲存

Google Sheets 尚未串接。後續可把 Google Sheet 作為共用單字來源，並以一列一個單字、欄位分為韓文與中文的方式管理；網站目前不會讀寫任何 Google Sheet，也不需要在 repo 中放入 Google 憑證。
